check in, please — 三日可玩 Demo v0.4.1 单层显示与 WASD 操作

双击 CheckInPlease.exe 启动。
请保留整个文件夹，不要单独移动 exe 或删除 CheckInPlease_Data、MonoBleedingEdge 等运行目录。

WASD 按画面方向移动（W 上、S 下、A 左、D 右）；也可点击地面寻路、点击场景标签走近互动。
按 WASD 会接管鼠标寻路。斜向移动不会加速；墙壁、家具、关闭的门和楼层边界会阻挡移动。
审查、举报、日志及暂停界面打开时不能移动；手动移动停止时自动保存位置。
一楼是前台与办公室电脑；二楼为 201–203，三楼为 301–303，共六间可分配的客房。
左上方楼层按钮和右上角地图会让人物实际走到楼梯并上下楼，不会瞬移。
两段西侧折返楼梯连接三层，爬楼过程自动完成；到达平台后切换楼层画面。
到达客房楼层后，顶部选择当前楼层房号，再开关门、安装摄像头、改变安装点、转向或切换视角。
201 初始配有摄像头。其余房间无摄像头，全部房门初始关闭。
没有观察来源的内部全黑；摄像头只显示覆盖区域。开门后的可见区域随人物位置变化。
家具不遮挡视野，但会阻挡行走。摄像头只能观察，搜查需要开门后走近物品。
白天可以查看楼层与调整监控朝向；开门、安装或移动摄像头需要等到夜班。
J：打开日志。Esc：返回或暂停。暂停菜单可以关闭环境音。

流程：晨间简报 → 走到一楼前台审查三名来客并分配房间 → 沿楼梯上楼、夜间搜查 → 下楼到办公室电脑提交举报 → 每日结算。
前台审查与电脑举报必须走到对应位置。电脑仍支持封存、销毁和外泄等原有情报处置。
每天的新规都要重新检查。违规放行的处罚在次日到达，最后一日则由最终复核结算。
每夜最多搜查四处；举报需要同一住客的两个独立来源。
可以举报、封存、销毁线索，或交给地下联络人。三个营业日结束后得到结局。

重要操作会自动保存。标题页“继续游戏”读取上次进度；重新开始需要再次点击确认。
存档位置：%USERPROFILE%\AppData\LocalLow\Northern District\Check In Please\hotel-save-v1.json

整座旅馆统一采用侧上方固定正交镜头和三维剖顶结构，房间观察保留柔和边缘。任意时刻只显示一层，上下楼期间也不叠加其他楼层。家具暂不支持自由移动。所在楼层、人物位置、摄像头和房门设置随存档保留，原有 v1 存档可以继续使用。尚不包含完整长篇剧情。
